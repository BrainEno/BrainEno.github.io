# 主题色的边界

编辑 `content.theme`（默认内容或发布快照），然后重新静态导出即可；没有运行时管理后台。

| 值 | 使用位置 |
| --- | --- |
| `stage` → `--stage` | 页面舞台、离线页背景，以及浏览器 `theme-color` 和安装清单的背景 / 主题色。 |
| `accent` → `--accent` | 首页强调元素、作品详情链接的悬停色、离线重试链接。 |
| `--ink`、`--muted` | 深色背景上的前景和辅助文字；与字体栈一同定义于 `src/app/globals.css`。 |

根布局在导出时把主题变量写入 `<html>`，不要在页面组件内重新定义。电视图像的采样色、显像管光效与电话亭配色不是品牌主题令牌，不应按相似色值批量替换。新增交互色请先判断它属于页面主题还是场景素材。普通滚动、放映时间线不依赖此主题机制。
